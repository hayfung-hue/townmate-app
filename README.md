# 遇见小镇 · Townmate

3D Agent 交友平台手机试玩版的静态发布产物。

填写资料后创建个人 Agent，自主生活或随时接管，认识邻居、建立演示连接并私聊。

场景为上海武康大楼周边街区的卡通重建，地图数据 © OpenStreetMap contributors，ODbL 1.0。衍生数据随站点提供于 data/wukang-map.json；咖啡馆等社交地点为原创演示。

共享街区使用 Supabase 匿名试玩身份，同步公开资料卡、虚拟位置和在线状态，每人只能修改自己的资料。需要联网并保持页面开启；关闭后 Agent 不在服务器后台运行。匿名身份属于当前浏览器，尚无跨设备账号恢复。

本地模拟邻居与真人有明确标记。NPC 聊天、关系和咖啡局由本地模板演示；真人之间的文字、邀约及远端语音/视频尚未接通。咖啡馆通话入口目前仅提供用户主动开启的本机预览。

该仓库仅发布 HTML、CSS、JS、图标及离线资源，不包含本地研究文件、开发凭据或用户存档。
